Setup guide

You manage everything from here. Only three things need a one-time setup — step by step below. No secret (API key, token) is ever saved on this page or in the catalog.

1. Publishing (GitHub)

Any change you make to the store (products, payments, images, settings) goes live only when you press Save & publish. That needs a GitHub token — just once.

  1. Open github.com/settings/tokens and create a Fine-grained token.
  2. Under Repository access choose only your store repo, and give Permissions → Contents: Read and write.
  3. Copy the token and paste it in the GitHub & publish section. The token stays only in your browser (localStorage) and is never sent anywhere.

2. Payments and contact

Fill UPI ID, bank details and the Razorpay link in the Payments section. Add the WhatsApp number and social links in Store settings. Any field you leave blank will not appear at checkout or in the footer.

3. AI assistant (Studio Genie)

The assistant works even without setup (it uses the built-in knowledge base). For real AI answers, deploy the Cloudflare Worker once — the key stays only as a Cloudflare secret, never in the website or catalog.

  1. Create a free account at dash.cloudflare.com.
  2. On your computer, go to this project's worker folder and run: npx wrangler deploy
  3. Set your AI key as a secret (one, named after the provider): npx wrangler secret put USER_LLM_API_KEY
  4. After deploy, copy the URL you get (for example https://kak-ai-proxy.xxx.workers.dev) into the AI API endpoint field in the Chat assistant section and publish.

4. Customer login / order history

Optional — guest checkout always works. If you want it, console.firebase.google.com create a free project, add a Web app, and paste its config in the Customer accounts section. Also paste the Firestore rules shown there. The Firebase config is public (it only identifies the project), while customer data is protected by the rules.

What is public?

  • Products, prices, images, UPI/bank/Razorpay — customers need to see these, so they are public.
  • GitHub token — only in your browser, never published.
  • AI key — only in the Cloudflare Worker secret, never in the repo or browser.
  • Admin PIN (if you set one) — in your browser in hashed form.

Shop / Products

Edit any field, add or remove products, and upload product images from your device. Uploaded images are stored in the repository under public/brand/products. Click Save & publish at the bottom to make changes live (about one minute).

Categories & subcategories

Add or edit the categories shown on the home page circles and the shop filters. Each category can have subcategories. Assign a product to a category and subcategory in Shop / Products. The ID is a short slug (no spaces) used in links — keep it stable once products use it.

Homepage content

These control the storefront sections on the home page: the announcement bar, category circles, the "why shop with us" strip, customer reviews and the newsletter. Reviews are placeholders — replace them with real customer words before going live.

B2B & wholesale

This controls the B2B / wholesale page (linked from the top menu and footer). Use it for trade, corporate gifting, private label and contract-manufacturing enquiries. All text here is yours to edit.

Site images

Change the images used across the website — the logo, the home page hero and gallery, the studio seal and the chat assistant. Upload a new image for any slot, then click Save & publish at the bottom. Square or landscape photos work best; large files are resized automatically.

Orders

Sign in with an owner email (set in Customer accounts) to see every order and update its status. Customers only ever see their own orders.

Payments

These details are shown to customers at checkout. Fill in whichever methods you accept; leave the rest blank to hide them.

Shipping charges

Set a flat shipping fee added at checkout. Orders above the free-shipping amount ship free. Turn this off to not add any shipping charge.

If a customer's PIN code starts with one of these prefixes, that rate is used instead of the flat fee. Free-shipping-above still applies first. Use the longest matching prefix for areas inside a region.

Discount codes

One code per line in this format: CODE | percent or flat | value | minimum order. Example: WELCOME10 | percent | 10 | 0 (10% off, no minimum) or FLAT200 | flat | 200 | 2000 (₹200 off above ₹2000). Codes are case-insensitive.

Chat assistant

The chat bubble shown on the website answers customer questions using your products, prices, payment and shipping details, your studio address, the business information below and the knowledge base.

Real AI (optional): to use a real AI (Gemini / GPT / DeepSeek), deploy the included Cloudflare Worker and paste its URL in AI API endpoint. Put the AI provider's API key as a secret on the Worker (USER_LLM_API_KEY) — never paste the key here or in the public site. Leave the endpoint empty to use the built-in assistant, which answers from the same information below without any key.

Customer accounts (login)

Turn on customer login and order history. This uses Firebase (Google) — it has a free plan. Create a project at console.firebase.google.com, add a Web app, and paste its config values below. Then enable the sign-in methods you want (Email/Password and/or Google) under Authentication, and create a Firestore database under Firestore Database. Login is optional for customers — guests can still checkout without an account.

These config values are public by design (they only identify your project).
