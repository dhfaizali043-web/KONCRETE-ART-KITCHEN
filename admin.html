Setup guide

Sab kuch yahin se manage hota hai. Sirf teen cheezein ek baar set karni hain — neeche step-by-step. Inme koi bhi secret (API key, token) is page par ya catalog me save nahi hota.

1. Publish karna (GitHub)

Store par jo bhi change karo (products, payments, images, settings) wo tabhi live hota hai jab tum Save & publish dabate ho. Uske liye ek GitHub token chahiye — sirf ek baar.

  1. Kholo github.com/settings/tokens par Fine-grained token banao.
  2. Repository access me sirf apna store repo chuno, aur Permissions → Contents: Read and write do.
  3. Token copy karke GitHub & publish section me paste karo. Token sirf tumhare browser me (localStorage) rehta hai, kahin bhej nahi jaata.

2. Payments aur contact

Payments section me UPI ID, bank details aur Razorpay link bharo. Store settings me WhatsApp number aur social links. Jo field khaali chhodoge wo checkout/footer par dikhega hi nahi.

3. AI assistant (Studio Genie)

Bina kuch setup kiye bhi assistant kaam karta hai (built-in knowledge base use karta hai). Asli AI answer chahiye to ek baar Cloudflare Worker deploy karo — key sirf Cloudflare me secret ke roop me rahegi, website/catalog me kabhi nahi.

  1. Free account banao dash.cloudflare.com par.
  2. Computer par is project ke worker folder me jao aur ye chalao: npx wrangler deploy
  3. Apni AI key secret ke roop me set karo (provider ke naam se ek): npx wrangler secret put USER_LLM_API_KEY
  4. Deploy ke baad jo URL mile (jaise https://kak-ai-proxy.xxx.workers.dev) wo Chat assistant section ke AI API endpoint me paste karke Publish karo.

4. Customer login / order history

Optional hai — guest checkout hamesha chalta rahega. Chahte ho to console.firebase.google.com par free project banao, ek Web app add karo, aur uski config Customer accounts section me paste karo. Wahan diye gaye Firestore rules bhi paste kar dena. Firebase config public hoti hai (sirf project identify karti hai), customer data rules se protected rehta hai.

Kya public hota hai?

  • Products, prices, images, UPI/bank/Razorpay — ye customers ko dikhne chahiye, isliye public hain.
  • GitHub token — sirf tumhare browser me, kabhi publish nahi hota.
  • AI key — sirf Cloudflare Worker secret me, kabhi repo/browser me nahi.
  • Admin PIN (agar set karo) — tumhare browser me hashed form me.

Shop / Products

Edit any field, add or remove products, and upload product images from your device. Uploaded images are stored in the repository under public/brand/products. Click Save & publish at the bottom to make changes live (about one minute).

Categories & subcategories

Add or edit the categories shown on the home page circles and the shop filters. Each category can have subcategories. Assign a product to a category and subcategory in Shop / Products. The ID is a short slug (no spaces) used in links — keep it stable once products use it.

Homepage content

These control the storefront sections on the home page: the announcement bar, category circles, the "why shop with us" strip, customer reviews and the newsletter. Reviews are placeholders — replace them with real customer words before going live.

Site images

Change the images used across the website — the logo, the home page hero and gallery, the studio seal and the chat assistant. Upload a new image for any slot, then click Save & publish at the bottom. Square or landscape photos work best; large files are resized automatically.

Orders

Sign in with an owner email (set in Customer accounts) to see every order and update its status. Customers only ever see their own orders.

Payments

These details are shown to customers at checkout. Fill in whichever methods you accept; leave the rest blank to hide them.

Chat assistant

The chat bubble shown on the website answers customer questions using your products, prices, payment details and the knowledge base below. One entry per line in the format Question | Answer.

Customer accounts (login)

Turn on customer login and order history. This uses Firebase (Google) — it has a free plan. Create a project at console.firebase.google.com, add a Web app, and paste its config values below. Then enable the sign-in methods you want (Email/Password and/or Google) under Authentication, and create a Firestore database under Firestore Database. Login is optional for customers — guests can still checkout without an account.

These config values are public by design (they only identify your project).
